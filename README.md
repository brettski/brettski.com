# brettski.com

Personal site and blog. Astro (static output), Tailwind CSS v4, Pagefind search, hosted on Cloudflare (Workers static assets), deployed from GitHub Actions.

## Commands

| Command                            | Action                                                                                                      |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `npm run dev`                      | Builds a search index, then starts the dev server (drafts visible). Restart to re-index after editing posts |
| `npm run build`                    | `astro build`, write `dist/_redirects`, build the Pagefind index                                            |
| `npm run preview`                  | Not used. Use `npx wrangler dev` to serve `dist/` with headers and redirects                                |
| `npm run lint`                     | ESLint and Prettier check                                                                                   |
| `npm run check`                    | `astro check` (types)                                                                                       |
| `npm test`                         | Vitest                                                                                                      |
| `npx tsx scripts/migrate-posts.ts` | One-time WordPress import (kept for reference)                                                              |

Node version is in `.nvmrc`.

## Add a post

Create `src/content/blog/<slug>.md`. The filename is the URL slug (`/blog/<slug>/`): lowercase letters, digits and hyphens only.

```md
---
title: 'Post title'
date: '2026-10-25T12:00:00.000Z'
tags:
  - programming
draft: false
description: 'Optional, used for meta tags and RSS'
---

Body in Markdown.
```

Images go in `public/images/blog/` and are referenced as `/images/blog/name.png`. Tags are lowercase slugs. The schema in `src/content.config.ts` fails the build on invalid front matter. Commit and push to `main` to publish. `draft: true` hides a post from production builds.

## Layout

```
public/                 static files, _headers (security headers/CSP)
scripts/                migrate-posts.ts, write-redirects.ts (post-build)
src/content/blog/       posts
src/content.config.ts   collection schema
src/lib/                pure, unit-tested logic (archive, tags, urls, pagination, redirects)
src/components/         Header, Footer, Logo, ThemeToggle, PostList, Pagination, Sidebar, TagList
src/layouts/            BaseLayout, BlogLayout
src/pages/              routes; add new top-level pages here
tests/                  content checks
```

## URLs

`/blog/`, `/blog/page/<n>/`, `/blog/<slug>/`, `/blog/archive/<year>/`, `/blog/archive/<year>/<mm>/`, `/blog/tags/`, `/blog/tags/<tag>/`, `/search/`, `/about/`, `/rss.xml`.

Legacy WordPress URLs are handled in `dist/_redirects`, generated by `scripts/write-redirects.ts`. Rules are per-year on purpose: a generic `/:y/:m/:d/:slug/` rule would also match `/blog/archive/<y>/<mm>/`.

## Design

- **Accent color:** `--color-accent-*` in `src/styles/global.css` points at Tailwind's emerald. Point it at another palette to re-theme the site. Light-mode text uses shade 700 and dark mode uses 400, which pass WCAG AA; shade 600 does not on white.
- **Fonts:** Inter and JetBrains Mono, self-hosted via `@fontsource-variable/*` (no external requests, so the CSP stays strict).
- **Dark mode:** `public/theme-init.js` (an external, synchronous script) sets `<html data-theme>` before first paint from the saved choice or the OS preference. `ThemeToggle.astro` switches and saves it. Tailwind's `dark:` variant follows `data-theme`.
- **Tag colors:** `src/lib/tagColor.ts` maps each tag to a fixed color by hashing its name. Classes are written out in full because Tailwind only generates classes it can see.

## Security

`public/_headers` sets a strict CSP (no inline scripts or styles, no third-party origins; `wasm-unsafe-eval` is for Pagefind), HSTS and related headers. Astro is configured never to inline CSS/JS to keep that possible. Don't add third-party scripts, fonts or images without updating the CSP. `tests/content.test.ts` fails on active-content HTML in posts and on external images.

## Deploy

Pushes to `main` run lint, typecheck, tests and build, then `wrangler deploy` (see `.github/workflows/ci.yml`). Pull requests run everything except the deploy.

One-time setup:

1. GitHub repo secrets: `CLOUDFLARE_API_TOKEN` (permission: Workers Scripts: Edit, scoped to this account) and `CLOUDFLARE_ACCOUNT_ID`.
2. Cloudflare: attach the custom domain `brettski.com` to the `brettski-com` Worker.
3. Old blog host: keep `blog.brettski.com` in Cloudflare DNS (proxied) and add a Redirect Rule: any request to host `blog.brettski.com` → dynamic redirect to `concat("https://brettski.com", http.request.uri.path)`, status 301, preserve query string. Old post, category, tag and archive URLs then land on `_redirects` rules.
